Il ciclo di una busta paga in Odoo
  1. Dipendente e contratto (hr.employee, hr.version): il contratto in corso indica paga base, orario di lavoro e struttura stipendio.
  2. Busta paga (hr.payslip) in Bozza: dal periodo si calcolano i giorni lavorati (orario + festività + assenze approvate) e si creano gli apporti previsti dalle regole.
  3. Calcola scheda: si prendono le regole della struttura e dei suoi padri (con le regole figlie), ordinate per sequenza. Per ognuna: se la condizione è vera si calcola l'importo → riga della busta. La busta passa In attesa e riceve il numero SLIP/xxx.
  4. Conferma → Completata. Da qui si può solo stornare (Storno = nota di credito) o, se abilitato, annullare.
  5. Gruppi buste paga (hr.payslip.run): generano le buste di tutti i dipendenti del periodo.
  6. Registri contributi: ogni riga può essere collegata a un registro (INPS, Erario…) per i report e per l'F24.

Esempi

Indennità di 3 € per ogni giorno lavorato (importo fisso, quantità):

quantità:      worked_days.WORK100 and worked_days.WORK100.number_of_days
importo fisso: 3

Contributo del 9,19% (percentuale negativa):

percentuale: -9.19      basata su: IMP_PREV

Codice Python su più righe:

base = categories.BASIC + categories.ALW
result_qty = inputs.STR25.amount
result_rate = 125
result = arrotonda(base / contract.divisore_orario, 5)
Convenzioni di Odoo da ricordare
  • Le trattenute sono negative e il netto è la somma delle categorie (BASIC + ALW + ESENTE + DED).
  • Un valore che non esiste vale 0: worked_days.PNR è 0 se non ci sono permessi non retribuiti, quindi si scrive worked_days.PNR and worked_days.PNR.number_of_hours.
  • Il codice di una regola è una variabile per le regole successive (GROSS, IMP_PREV); se la regola non è stata calcolata la variabile non esiste: meglio usare le categorie.
  • Le assenze sono di default negative nei giorni lavorati (Impostazioni → "Permessi con valore positivo").
